1.  Problèmes de carte graphique

-------------------------------------------------------------------

Matériel accélérateur 3D compatible :

SimCity 4 Deluxe/Rush Hour nécessite un composant 3D compatible
Direct3D de 32 Mo, une résolution minimum de 800 x 600 et doit
supporter le mode couleur 16 ou 32 bits. Il est conseillé d'installer
les pilotes certifiés les plus récents pour tout votre matériel.


Les cartes utilisant les composants suivants sont officiellement
compatibles avec le pilote d'affichage de SimCity 4 :


nVidia :


http://www.nvidia.com
 
- nVidia TNT2, TNT2 M64 et TNT2 Ultra

- nVidia GeForce SDR, GeForce DDR, GeForce Quadro,
GeForce2 GTS, GeForce2 MX, GeForce3, GeForce4 MX,
GeForce4 Ti 4200/4400/4600/4800 SE et GeForceFX 5200/5600/5800/5900


ATI :


http://www.ati.com

- ATI Radeon 7000, 7200, 7500, 8500, 9000, 9200, 9500, 9600, 9700 et 9800



Problèmes identifiés :

+ En raison de limitations matérielles de la série ATI Radeon, certains
  bâtiments et autres effets graphiques seront momentanément invisibles
  lors des déplacements.
+ Un défaut identifié avec certains pilotes ATI entraîne la perte
  d'affichage de certains des polygones du conseiller. Pour remédier à
  cela, veuillez télécharger le pilote ATI 7.79 (également dénommé CATALYST 02.4) ou une version
  ultérieure depuis l'adresse Internet
  suivante : http://www.ati.com



Matrox :

http://www.matrox.com
 
- Matrox G400, G450, G550, Parhelia


SiS :

http://www.sis.com

- SiS 315, Xabre 400




Accélération logicielle :

SimCity 4 possède également un pilote graphique logiciel qui fonctionne
avec la plupart des cartes graphiques. 32 Mo de mémoire vidéo sont
recommandés. Ce pilote peut être sélectionné
dans le panneau des options vidéo du jeu ou peut être modifié en
ajoutant -d:Software à la ligne de commande.


Les composants vidéo suivants fonctionneront correctement avec le jeu en
mode accélération logicielle :

- PowerVR KYRO, KYRO II
- Trident Blade 64

2.  Problèmes identifiés

----------------------------------------------------------------------


Logiciel antivirus : si un logiciel antivirus est activé pendant que
vous jouez à SimCity 4 Deluxe/Rush Hour, les performances du jeu
risquent d'être considérablement réduites.

Blocages occasionnels après la vidéo d'introduction sous Windows ME :
il arrive que SimCity 4 Deluxe/Rush Hour se bloque après la séquence
d'introduction sous Windows ME. Pour éviter cela, lancez le jeu en
ajoutant l'option -intro:off dans la ligne de commande. Cela désactivera
complètement la vidéo d'introduction.

Performances de SimCity 4 Deluxe/Rush Hour : vous pouvez modifier la
qualité visuelle et les performances du jeu en sélectionnant différentes
options graphiques. Pour changer ces paramètres, cliquez sur le bouton
Options, puis sur le bouton Options vidéo.

Problèmes de couleur du curseur : certaines cartes ont des
difficultés à afficher un curseur de couleur. Si le curseur se
met à trembler au cours du jeu, mettez à jour les pilotes de la carte
graphique et, si le problème persiste, désélectionnez Curseur de couleur
dans le panneau des options vidéo. Le curseur de couleur peut
également être désactivé avec l'option de ligne de commande -Cursors:bw

Anticrénelage sur plein écran (FSAA) : SimCity 4 Deluxe/Rush Hour ne
fonctionne pas si l'anticrénelage est activé. Cette option peut être
désactivée dans la fenêtre Propriétés d'affichage, sous l'onglet
Paramètres. Cliquez sur le bouton Avancé et trouvez l'onglet du
fabricant de votre carte graphique.

3.  Options de ligne de commande

-----------------------------------------------------------------------

Audio :

-audio:on|off	       Active ou désactive l'audio pour l'application
-music:on|off	       Active ou désactive la musique pour l'application


Vidéo :

-Cursors:bw|fullcolor	Définit la profondeur de couleur des curseurs
-d:DirectX|Software	Définit le pilote graphique pour SC4

4.  Configuration minimale nécessaire

------------------------------------------------------------------------
 
Windows 98 :

Processeur : PIII 500 ou équivalent 
RAM : 128 Mo 
Vidéo : carte graphique de 32 Mo compatible Direct3D avec pilote
compatible DirectX 7.0 ou plus récent
Espace disque dur : 1.6 Go
CD-ROM : 8X ou plus
Autres : DirectX 8.1
 
Windows Me, 2000, XP Home et XP Professionnel :

Processeur : PIII 500 ou équivalent 
RAM : 256 Mo 
Vidéo : carte graphique de 32 Mo compatible Direct3D avec pilote
compatible DirectX 7.0 ou plus récent
Espace disque dur : 1.6 Go
CD-ROM : 8X ou plus
Autres : DirectX 8.1
