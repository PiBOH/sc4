1.  Stöd för grafikkort

-------------------------------------------------------------------

3D-accelererad maskinvara som stöds:

SimCity 4 Deluxe / Rush Hour kräver ett 32MB Direct3D-chip och en 
upplösning på minst 800x600 med stöd för 16- eller 32-bitars färger.
Vi rekommenderar att du alltid installerar de senaste, certifierade
drivrutinerna till all maskinvara.


Kort med dessa chip stöds officiellt av grafikdrivrutinerna i
SimCity 4:


nVidia:


http://www.nvidia.com
 
- nVidia TNT2, TNT2 M64, & TNT2 Ultra

- nVidia GeForce SDR, GeForce DDR, GeForce Quadro, 
GeForce2 GTS, GeForce2 MX, GeForce2 GTS, GeForce3, 
GeForce4 MX, GeForce4 Ti 4200/4400/4600/4800 SE, och 
GeForceFX 5200/5600/5800/5900


ATI:


http://www.ati.com

- ATI Radeon 7000, 7200, 7500, 8500, 9000, 9200, 9500, 9600, 9700, 9800


Kända problem:

+ På grund av maskinvarubegränsningar i ATI:s Radeon-serie, försvinner 
  vissa byggnader och effekter tillfälligt när du flyttar kartbilden.
+ Det finns ett känt fel i ATI-drivrutinerna som gör att animeringen av
  rådgivarna i SimCity tappar polygoner. För att lösa detta laddar du 
  ner ATI:s drivrutin 7.79 eller senare (även känd som CATALYST 02.4)  
  från http://www.ati.com på Internet.



Matrox:

http://www.matrox.com
 
- Matrox G400, G450, G550, Parhelia


SiS:

http://www.sis.com

- SiS 315, Xabre 400




Programvaruläge:

SimCity 4 erbjuder även en programvarubaserad grafikdrivrutin som  
fungerar med de flesta grafikkort. 32MB grafikminne rekommenderas. Du 
kan välja grafikdrivrutin på grafikalternativpanelen i spelet eller 
köra den programvarubaserade drivrutinen med hjälp av kommandoraden 
-d:Software.


Följande grafikchip kan köra spelet i programvaruläge:

- PowerVR KYRO, KYRO II
- Trident Blade 64

2.  Kända problem

----------------------------------------------------------------------


Anti-virusprogram:  Om du har anti-virusprogram igång när du kör 
SimCity 4 Deluxe / Rush Hour kan det dra ner spelets prestanda markant.

Tillfälliga krascher efter inledningsfilmen under Windows ME:  Ibland 
kraschar SimCity 4 Deluxe / Rush Hour efter inledningsfilmen om det 
körs under Windows ME.  För att undvika detta kör du spelet med  
kommandoraden -intro:off.  Detta gör att inledningsfilmen inte spelas  
upp alls.

SimCity 4 Deluxe / Rush Hour spelprestanda:  Du kan ändra prestandan och 
grafikkvalitén i spelet genom att välja olika grafikalternativ. Om du  
vill ändra dessa alternativ klickar du först på alternativknappen och  
därefter på grafikalternativknappen.

Maskinvarustöd för färgmarkör:  Vissa grafikkort har problem med att visa 
en maskinvarustyrd färgmarkör. Om markören fladdrar till under spelets gång 
kan du prova att uppdatera grafikdrivrutinerna och, om det inte fungerar, 
välja bort färgmarkör i grafikalternativpanelen.  Du kan även stänga av den
maskinvarustyrda färgmarkören med kommandoraden -Cursors:bw

Anti-alias i fullskärmsläge:  SimCity 4 Deluxe / Rush Hour går inte att köra 
med anti-alias i fullskärmsläge påslaget.  AAFS kan slås av i fönstret 
Egenskaper för Bildskärm, under fliken Inställningar. Klicka på Avancerat- 
knappen och leta reda på grafikkorttillverkarens flik.


-----------------------------------------------------------------------

3.  Kommandoalternativ

-----------------------------------------------------------------------

Ljud:

-audio:on|off		Slår på eller av allt ljud i programmet
-music:on|off		Slår på eller av all musik i programmet


Grafik:

-Cursors:bw|fullcolor	Ställer in färgen på spelmarkören
-d:DirectX|Software	Ställer in programvarustyrd grafikdrivrutin i SC4

4.  Minimisystemkrav

------------------------------------------------------------------------
 
Windows 98:

CPU: PIII 500 eller likvärdig 
RAM: 128MB 
Grafik: 32MB Direct3D-kort som stöds och använder drivrutiner som är  
kompatibla med DirectX 7.0 eller senare
Diskutrymme: 1.6GB
CD-ROM: 8X eller snabbare
Övrigt: DirectX 8.1
 
Windows Me, 2000, XP Home och XP Professional:

CPU: PIII 500 eller likvärdig 
RAM: 256MB 
Video: 32MB Direct3D-kort som stöds och använder drivrutiner som är
kompatibla med DirectX 7.0 eller senare
Diskutrymme: 1.6GB
CD-ROM: 8X eller snabbare
Övrigt: DirectX 8.1
