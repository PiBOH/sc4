1.  Graphics Card Support

-------------------------------------------------------------------

Supported 3D Accelerator Hardware:

SimCity 4 Deluxe / Rush Hour requires a 32MB 3D Direct3D chipset, and a 
display that is at least 800x600 in size, and supports
16 or 32-bit color.  It is recommended to always install the latest
certified drivers for all your hardware


Cards with these chipsets are officially supported
by the SimCity 4 hardware graphics driver:


nVidia:


http://www.nvidia.com
 
- nVidia TNT2, TNT2 M64, & TNT2 Ultra

- nVidia GeForce SDR, GeForce DDR, GeForce Quadro, 
GeForce2 GTS, GeForce2 MX, GeForce2 GTS, GeForce3, 
GeForce4 MX, GeForce4 Ti 4200/4400/4600/4800 SE, and 
GeForceFX 5200/5600/5800/5900


ATI:


http://www.ati.com

- ATI Radeon 7000, 7200, 7500, 8500, 9000, 9200, 9500, 9600, 9700, 9800



Known Issues:

+ Due to hardware limitations with the ATI Radeon series, some 
  buildings and graphic effects will be temporarily turned off while 
  scrolling.
+ There is a known ATI driver defect that results in SimCity advisor 
  animations dropping polygons. To fix this, please download ATI 
  driver 7.79 or later (also referred to as CATALYST 02.4) from 
  http://www.ati.com on the Internet.



Matrox:

http://www.matrox.com
 
- Matrox G400, G450, G550, Parhelia


SiS:

http://www.sis.com

- SiS 315, Xabre 400




Software Mode:

SimCity 4 also provides a software-based graphics driver which will 
work with most video cards. 32MB of video memory is recommended. The 
graphics mode driver can be selected from the Graphics Options panel
in the game, or may be run from the command line using the 
switch -d:Software.


The following video chipsets will run the game properly in software mode:

- PowerVR KYRO, KYRO II
- Trident Blade 64

2.  Known Issues

----------------------------------------------------------------------


Anti-virus Software:  having anti-virus software enabled while playing
SimCity 4 Deluxe / Rush Hour can significantly degrade the performance 
of the game.

Occasional Crashes after Playing Opening Movie under Windows ME:  There
is an occasional crash in SimCity 4 Deluxe / Rush Hour running under 
Windows ME after the intro movie completes.  To avoid this crash, run 
the game with the command line option -intro:off.  This will disable 
the opening movie completely.

SimCity 4 Deluxe / Rush Hour Game Performance:  You can adjust the 
performance and visual quality of the game by selecting different 
graphics options.  To change these settings, click the options button, 
then the graphic options button.

Hardware Color Cursor Support:  Some cards have problems displaying a 
color hardware cursor. If cursor flickering occurs while playing the game, 
try updating the graphics drivers, and, failing that, deselecting Color 
Cursor in the Graphic Options panel.  Additionally, color hardware cursors
can be turned off with the command line option -Cursors:bw

Full-screen Anti-aliasing:  SimCity 4 Deluxe / Rush Hour will not run with 
full-screen anti-aliasing turned on.  FSAA may be turned off in the Display 
Properties window, under the Settings tab.  Select the Advanced button and 
then find the graphics card manufacturer's tab.

3.  Command Line Options

-----------------------------------------------------------------------

Audio:

-audio:on|off		Enables or disables all audio for the application
-music:on|off		Enables or disables all music for the application


Graphics:

-Cursors:bw|fullcolor	Sets the color depth of the game cursors
-d:DirectX|Software	Sets the graphics driver for SC4

4.  Minimum System Requirements

------------------------------------------------------------------------
 
Windows 98:

CPU: PIII 500 or equivalent 
RAM: 128MB 
Video: 32MB supported Direct3D capable video card with DirectX 7.0 or greater
compatible driver
Disk Space: 1.6GB
CD-ROM: 8X or faster
Other: DirectX 8.1
 
Windows Me, 2000, XP Home, and XP Professional:

CPU: PIII 500 or equivalent 
RAM: 256MB 
Video: 32MB supported Direct3D capable video card with DirectX 7.0 or greater
compatible driver
Disk Space: 1.6GB
CD-ROM: 8X or faster
Other: DirectX 8.1
