Release policy

Version numbers are stored in .tools/version.txt. A GitHub Actions workflow validates every locale archive, creates a clean source package, generates a SHA-256 checksum, and publishes the release.

Push commits whose message starts with v trigger the automatic release job. That initial v is only a workflow trigger marker; it is not added to the release tag or release name. Manual workflow dispatch is also supported.
