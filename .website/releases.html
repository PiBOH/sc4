Each release includes the full source package and a per-language ZIP for direct download. Versions use Semantic Versioning 2.0.0; -stable marks a stable release.

Release policy

The version is stored in .tools/version.txt. A push commit to main whose message starts with v triggers the automatic release. The v is only a trigger marker; it is not included in the release tag or name. Each automated release includes the clean source package, its SHA-256 checksum, and a ZIP file per language.
