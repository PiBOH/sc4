Releases

Each release includes the full source package, per-language ZIPs, the all-languages ZIP, and the plugins ZIP, all with SHA-256 checksums.

Current version

0.0.3-stable — the latest archive set with updated UI labels across all supported languages, DBPF/RefPack tooling, per-language ZIP assets, the plugins package, and validation workflows.
Download from GitHub Releases

Release policy

The version is stored in .tools/version.txt. A push commit to main whose message starts with v triggers the automatic release. The v is only a trigger marker; it is not included in the release tag or name.
