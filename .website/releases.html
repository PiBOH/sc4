Releases

Each release includes the full source package and a per-language ZIP for direct download. Versions use Semantic Versioning 2.0.0; -stable marks a stable release.

Current version

0.0.3-stable — the latest archive set with updated UI labels across all supported languages, DBPF/RefPack tooling, per-language ZIP assets, and validation workflows.

Download from GitHub Releases

Release policy

The version is stored in .tools/version.txt. A push commit to main whose message starts with v triggers the automatic release. The v is only a trigger marker; it is not included in the release tag or name.
