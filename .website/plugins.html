Plugins

Plugins tested and recommended for SimCity 4 Deluxe Edition, ready to copy into %USERPROFILE%\Documents\SimCity 4\Plugins. Download Plugins.zip from the latest release; it contains the Plugins/ folder with every file below.

Download Plugins.zip

SC4 Disable FPS Limits

Removes the default FPS caps during simulation speeds (Turtle 30 FPS, Rhino 20 FPS, Cheetah 15 FPS), letting the game run at up to 255 FPS at every speed. Configuration is read from SC4DisableFpsLimits.ini next to the DLL.

  • Files: SC4DisableFpsLimits.dll, SC4DisableFpsLimits.ini (and the upstream SC4 Disable FPS Limits DLL v0.2.3.zip archive).
  • Configuration: MaxFPS (1–255, capped at 255) applies to all simulation speeds; LogLevel sets log verbosity (trace, debug, info, warn, error, critical, off).
  • Official requirements: SimCity 4 v1.1.641, Windows 10 or later.
  • License: GNU LGPL v2.1 or later.
  • Upstream: caspervg/sc4-disable-fps-limits

SimCity 4 Extra Cheats Plugin

Adds additional cheat shortcuts to the game. This is the well-known third-party plugin from 2006, included as-is.

  • Files: SimCity 4 Extra Cheats Plugin.dll (and the original extra_cheats_plugin.zip archive).
  • Recommended for: not required, but highly recommended on SimCity 4 versions prior to v1.1.641.
  • License: historical third-party plugin; distributed under its original terms.

Installation

  1. Close SimCity 4 completely.
  2. Download Plugins.zip and extract its contents.
  3. Copy the files into your Plugins folder: %USERPROFILE%\Documents\SimCity 4\Plugins (the same as <My Documents>/SimCity 4/Plugins; create it if it does not exist).
  4. Start SimCity 4. The FPS Limits plugin writes SC4DisableFpsLimits.log in the same folder for troubleshooting.
