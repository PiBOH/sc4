Install a locale archive

Close SimCity 4, back up the original file, then replace it with the archive for your chosen language. These files are tested against SimCity 4 Deluxe v1.1.610 and are compatible up to v1.1.641.

Before you start

Close SimCity 4 completely before touching any locale file.

Installation steps

  1. Choose your language. See the language table for the matching folder.
  2. Download the archive. Use the latest package or per-language ZIP from GitHub Releases.
  3. Back up the original. Find the existing SimCityLocale.dat or SimCityLocale.DAT in your game installation and copy it somewhere safe.
  4. Replace the file. Copy the chosen locale archive into the corresponding language folder, keeping the original filename.
  5. Launch the game. Start SimCity 4 and use the language configuration for your installation.

Finding the game folder

Look inside the SimCity 4 installation directory for language folders such as English, French, or Italian. The repository folder names intentionally match the original package names, including the historical spelling of Norwgian and Portgese.

Rolling back

Restore the backup you made before replacing the original. Do not use a .BAK copy as a game file unless you rename it back to the original filename.
