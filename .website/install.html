Five easy steps

Install a locale archive.

Replace the game's locale file with the archive for your chosen language. Always keep an original backup.

Before you start

Close SimCity 4 completely. Make sure you have a working backup of the original file before replacing anything.

!

Use the correct game installation

These files are tested against SimCity 4 Deluxe v1.1.610. Other editions or patches may use different paths or archives.

The installation steps

  1. Choose your language. Open the language table and identify the matching repository folder.
  2. Download the archive. Use the latest package from the GitHub Releases page.
  3. Back up the original. Find the existing SimCityLocale.dat or SimCityLocale.DAT in your game installation and copy it somewhere safe.
  4. Replace the file. Copy the selected locale archive into the corresponding language folder, keeping the original filename and extension spelling.
  5. Launch the game. Start SimCity 4 and use the language configuration appropriate for your installation.

Finding the game folder

The exact location depends on your store and operating system. Look inside the SimCity 4 installation directory for language folders such as English, French, or Italian. The repository folder names intentionally match the original package names, including the historical spelling of Norwgian and Portgese.

Rolling back

To undo the installation, restore the backup you made before replacing the original archive. Do not use a .BAK working copy as a game file unless you rename it back to the original filename.
